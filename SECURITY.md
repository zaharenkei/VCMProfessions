# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or a potential security issue related to this mod, please report it privately.

**Please do not disclose security vulnerabilities through public GitHub Issues or Discussions.**

Instead, use GitHub's **Report a vulnerability** feature on this repository's Security tab.

When submitting a report, please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The version of the mod affected.
- The potential impact of the vulnerability.
- Any relevant logs or screenshots (make sure to remove personal information).

## What to Expect

I'll review submitted reports and investigate the issue.

If the vulnerability is confirmed, I'll work on a fix and release an update when possible.

Please allow reasonable time for investigation and remediation before making the vulnerability public.

## Scope

This policy covers security issues directly related to this mod and its source code.

Issues related to Project Zomboid itself, Steam, or other third-party software should be reported to their respective maintainers.

## Supported Versions

Security fixes will generally be provided for the latest available version of the mod.

Older versions may not receive security updates.
